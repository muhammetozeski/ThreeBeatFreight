# Knowledge method

Keep project-specific rules, authorization boundaries, diagnosed failures and verified operating methods in this library. Explain the condition, actual source/operation, expected result and evidence. Source inspection, controlled checks and production observations are different evidence types.

Link each new topic from INDEX.md. General platform tutorials belong in primary-source links; temporary plans and raw outputs belong outside this library. Update the existing source of truth when its behavior changes. Never convert a design proposal or owner intention into an executed result or user approval.
