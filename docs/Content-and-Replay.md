# Authored dispatches and repeat play

Twelve original yards have different wall pockets, conveyor directions, shock phases, pit gates and supply sources. They are maps in one game, not twelve independent products. The 24 authored contracts teach cargo delivery and progressively raise its target. They are intentionally solvable without a rival; they do not represent 24 different rule systems.

A disposable fixture fed actual three-command programs into the production engine. All 24 contracts were completed with zero recoveries (61 assertions including map validation and deterministic daily selection). A contract's route proof establishes playability, not human difficulty, balance or measured enjoyment. Some training routes are short; human interception is the main competitive uncertainty.

The local dispatch bot uses only public pre-round state. It scores a bounded set of 264 possible programs by simulated delivery, cargo possession, distance, recovery and energy. It never receives the player's selected program. Its simulation is the same `resolveRound` module used by rooms. It is explicitly labeled an automated local opponent and never enters the online identity/participant tables. A controlled six-round example deterministically delivered four crates; 19 assertions checked plan validity, unchanged inputs and reproducibility. That result is a simulation, not a player record.

The UTC dispatch of the day is a date-selected featured existing contract, not a claim of freshly authored daily content. Local results list the best round count and remain editable browser data. Online rematch creates a fresh lobby; it does not automatically enroll or consent for other couriers.

The arena lab supports actual tile painting, docks and loading-source placement plus a strict raw JSON option. Shared arena validation bounds dimensions and fields, requires distinct plain-floor docks/sources, and traverses routes from every dock to every source. That is reachability validation, not proof of multiplayer balance. Local field tests and automated-rival matches use the resulting board. Arena JSON packages import/export without keys or external assets.

Replay packages carry recorded public state and revealed programs. The replay theatre validates bounded data and offers read-only beat/round playback. It labels the file as supplied content, not a server-verified ranking. Opening it leaves the saved local match intact; start a new match to resume interactive play. The actual browser-module consumer fixture passed 17 assertions with the network disabled, including first delivery, records, arena roundtrip, invalid arena refusal, replay roundtrip, read-only commit refusal and local-rival resolution. This exercised the JavaScript module with consumer browser primitives; it was not a graphical browser session.

The copied appearance guard is active on app and privacy HTML. It computes rendered contrast, alpha composition and repairs unreadable foregrounds against the 4.5 target. Fifteen assertions exercised its actual color functions and the product's principal solid text pairs. Human rendering and assistive-technology review are separate from these calculations.
