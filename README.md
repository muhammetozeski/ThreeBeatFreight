# Three Beat Freight

An independent browser cargo-arena game in development. A player plans three short commands, then watches movement, cargo and collisions resolve. Private multiplayer rooms and solo contracts use the same deterministic game module. Source and publication claims are added only after verification.

This project lives permanently in this directory. The original game content, client, service, schema and publication tooling belong here; disposable checks belong in the separately allocated temporary check folder.

## Source map

- `game/`: shared rules and original arena/contract definitions.
- `src/ThreeBeatFreight.Client/`: the English Blazor browser client.
- `server/`, `functions/`, `schema/`: real room sessions, durable game state and authorization.
- `scripts/`: checks, build and owner-operated publication/configuration.
- [Project knowledge](docs/INDEX.md) and [continuation method](Walkthrough/Guide.md).

There are no invented players, audience statistics or promised earnings. Purchases and third-party advertising require real owner configuration; unavailable payment or advertising configuration must not be presented as an active service.
